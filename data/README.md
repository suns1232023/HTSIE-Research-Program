# HTSIE Research Data Directory

本目录用于存放 HTSIE 研究程序的每日自动化实验数据与计算指标。

## 📂 文件说明

- `metrics.json`: 每日自动运行导出的最新结构指标（包含有效维度 $d_{eff}$、知识熵 $S_k$ 等）。
- `daily_log.md`: 持续追加的自动化执行历史日志。
- `raw_activations.npy`: 本地生成的临时/测试激活矩阵文件（大文件请转存至 OpenXLab）。

> **注意**：大型数据集中转与持久化存储请访问：[OpenXLab HTSIE Dataset](https://openxlab.org.cn/datasets/suns1232026/HTSIE)
